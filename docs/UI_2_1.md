# Nebula 2.1 UI/readability specification

## Contrast

Dark surfaces use explicit near-white `onSurface`, lavender `onSurfaceVariant`, white primary-button content, and visible disabled icon colors. Light surfaces use dark purple-gray text. Search fields no longer combine a hardcoded dark container with light-theme dark text.

## Webpage space

The old website layout could consume roughly 130–150dp with an address bar and a second navigation dock. Nebula 2.1 uses one 52dp address field with compact back/reload/tabs/menu controls while reading webpages. Home and Workspace retain a separate 58dp navigation dock.

## System bars

The app uses dark system status/navigation bars and light system icons. This avoids white-on-white status text when a webpage has a white background. Content remains within Android safe drawing insets.

## Visual language

The background is drawn locally with Compose Canvas: nebula radial clouds, deterministic stars, purple/cyan orbital waves, and a layered 3D planet logo. No remote wallpaper or tracking service is used.
